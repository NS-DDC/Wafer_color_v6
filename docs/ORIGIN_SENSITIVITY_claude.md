# 격자 원점 (x0, y0) 파라미터 민감도

`sweep_origin_claude.py` 자동 생성. baseline = `ColorProfile()` 기본값.

- `lat` = 원점이 **격자 몇 칸** 움직였나 (0 이 아니면 die 인덱스가 통째로 밀림)
- `sub` = 같은 칸 안에서의 잔차 px (작으면 무해)
- `Δpitch` = pitch 변화. 이게 깨지면 origin 이 같아도 **다른 격자**다.
- `Δdies` = 검출 die 개수 변화
